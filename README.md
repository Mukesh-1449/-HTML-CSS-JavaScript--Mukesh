## How to Run
1. Extract/open this project folder.
2. Open `index.html` in a web browser.
3. Select HTML Programs, CSS Programs, or JavaScript Programs.
4. Select any experiment using the **Open Program** link.
5. Use the navigation bar on every page to return to Home or the relevant program list.

No server is required for the core project; the HTML files can be opened directly in a browser.
